# mlx-audio-io 1.2.1

Date: 2026-03-01

## Fixes

- Added MLX runtime compatibility preflight before native import.
  - `mlx_audio_io.load(...)` now fails with a clear `RuntimeError` when the runtime
    `mlx` version does not match the native wheel build version.
  - This prevents native aborts caused by MLX ABI/runtime mismatch.
- Added build-time MLX version metadata (`build_mlx_version`) to wheel build info.
- Added runtime MLX diagnostics (`runtime_mlx_version`, `mlx_version_matches`) to
  `show_build_info()` and `python -m mlx_audio_io.doctor`.

## Why this release

In mixed environments where `mlx-audio-io` was installed without dependency
resolution (for example `pip install --no-deps`), runtime `mlx` mismatches could
cause native aborts in load/save paths. This release adds a fail-fast package-level
guard so the issue is surfaced as a deterministic Python error with remediation.
