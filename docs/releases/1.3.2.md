# mlx-audio-io 1.3.2

## Fixed

- Hardened WAV fast-path PCM conversion to avoid overlapping source/destination
  buffers during int16/int32 to float32 conversion.
  - Applies to both macOS and Linux backends.
- Switched returned audio tensors to copy into MLX-owned storage before returning.
  - Avoids pointer-lifetime instability when many `load()` / `stream()` results are
    produced in a single process.

- `tests/test_stream.py`
- `tests/test_resample.py`
- SongPrep in-process integration smoke run with `--audio-backend mlx_audio_io`
  and MLX generation.
