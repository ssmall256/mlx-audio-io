# mlx-audio-io 1.3.11

## Changed

- Rebuilt the release line for MLX `0.31.2`.
  - macOS runtime pin: `mlx==0.31.2`
  - Linux runtime pin: `mlx[cpu]==0.31.2`
- Pinned the extension build to `nanobind==2.12.0`, matching the typed
  `mlx::core::array` bridge required by MLX `0.31.2`.
- Updated the native extension build to C++20, which MLX `0.31.2` headers now
  require on source builds.
- Kept exact MLX pinning. The native extension still rejects runtime MLX
  versions that differ from the build-time MLX version.

## Why This Release

Downstream packages that need to validate against MLX `0.31.2` could not resolve
with `mlx-audio-io==1.3.10`, because that release intentionally pins MLX
`0.31.0`. This release provides the matching native audio I/O package for the
MLX `0.31.2` runtime line.
